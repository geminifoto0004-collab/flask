# 手機版：單張訂單 PDF / 分享 / 詳情排序

日期：2026-08-16

## 本版修改

1. 單張訂單詳情的「訂單資料」移到時間軸與圖片之前。
2. 單張訂單詳情新增「生成 / 分享本單 PDF」。
3. 單張 PDF 直接沿用現有 customer_report.py 與 /api/customer-reports/jobs；只送目前這一筆 items，因此不重寫 PDF 生成器。
4. 客戶頁原「生成報告」改為更明確的「全部訂單 PDF」，與單張 PDF 分開。
5. PDF 完成後，分享按鈕排列第一並作為主按鈕。按下後使用 Web Share API 呼叫手機原生分享面板；不必先開 PDF 再按瀏覽器右上角分享。
6. 瀏覽器本身右上角的分享鍵仍可照常使用，但網頁程式不能代替使用者去點 Chrome/Safari 的瀏覽器工具列按鈕。
7. 單張報告檔名會加入訂單 / 流程號，方便在分享面板辨識，例如：
   `FRANCISCO_GONZALES_1008217-1_订单报告_20260816.pdf`
8. Render Cloud Mode 目前仍不會假裝可即時生成本地完整 PDF；等 report_requests 接 TiDB 後，單張與全部兩種請求都可加入 queue。

## 手機單張訂單版面順序

- 客戶 / 訂單號 / 狀態
- 訂單資料
- 生成 / 分享本單 PDF
- 進度時間軸
- 圖片（區域網路 / Local 模式）
