# 手机客户页订单图片：卡片内直接左右滑动

本次只修改手机，不修改桌面 Web。

调整：
- 删除订单卡片图片中间重复显示的订单号。
- 订单号 + 状态继续保留在卡片底部渐变区域。
- 修正「已经有图片但仍显示 暂无图片」的问题。
- 每张订单卡片现在可以直接左右滑动浏览该订单的多张图片。
- 多图会显示小圆点和 1/N。
- 左右滑动图片不会误触进入订单详情。
- 单纯轻点卡片仍可进入完整订单详情（时间轴、资料、PDF 等）。
- 为避免一次加载大量图片：
  - 每个客户页最多仍使用 4 个并发请求读取订单图片清单。
  - 每张订单初始只下载第一张图片。
  - 其它图片等用户滑到附近时才下载。
