# 客户页状态筛选（手机内部页 + 临时 Guest）

更新：2026-08-17

## 内部手机客户 PERFIL
- 在「订单」标题下新增横向状态筛选按钮。
- 「全部」+ 当前客户实际存在的每个精确状态（例如：已完成、图稿待确认、生产中）。
- 每个按钮显示数量。
- 进入订单详情再返回时，保留当前客户的状态筛选；原有返回定位/焦点逻辑继续生效。
- 仅前端筛选当前客户已经加载的订单，不改变数据库/API/权限。

## 办公室临时 Guest 客户页
- 同样新增 `Estado` 横向状态筛选：`Todos` + 当前客户实际存在的状态。
- 使用既有西班牙文状态标签；每个按钮显示数量。
- 筛选选择保存在该临时 token 的 sessionStorage 中，因此进入订单详情再返回时仍保持原筛选。
- Guest 权限边界不变：仍只能看到 token 所绑定客户，筛选不会请求或暴露其他客户资料。
- 页面重新进入/刷新仍重新读取最新订单与附件；状态筛选不是数据缓存。
