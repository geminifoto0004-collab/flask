# 手机单张订单：主图优先布局

日期：2026-08-16

本版仅修改手机单张订单详情（<=768px），桌面 Web UI、桌面表格、桌面筛选、Workspace 与后端业务逻辑均未改动。

## 手机单张订单新顺序

有图片：
1. 顶部图片轮播（左右滑动）
2. 客户 / 订单号 / 当前状态
3. 订单资料
4. 生成 / 分享本单 PDF
5. 进度时间轴

无图片：
1. 客户 / 订单号 / 当前状态
2. 订单资料
3. 生成 / 分享本单 PDF
4. 进度时间轴

## 图片轮播
- 只在本地 / LAN 模式读取订单图片与流程图片。
- Render Cloud Mode 不显示图片区。
- 第一张图优先加载，其余 lazy load。
- 左右滑动使用 CSS scroll-snap。
- 右上显示 1 / N。
- 底部显示分页点。
- 点击任何图片仍进入现有手机全屏图片预览。
- 没有图片时整个图片区不渲染，不留空白。

## 桌面保护
- 新 CSS 全部包在 `@media (max-width: 768px)`。
- JS 只修改 `renderMobileOrderDetail` 及手机图片渲染函数。
- 未修改任何桌面 order table / filter / workspace 渲染函数。
