# 手机历史返回修正：订单 -> 客户页 -> 返回订单

本次只修改手机浏览器 history 行为，桌面 Web 不改。

## 正确规则

- 首页「按订单」 -> 某订单 -> 点击客户名字 -> 客户页 -> 左滑 / 返回：回到刚才那张订单。
- 首页「按客户」 -> 某客户 -> 某订单 -> 点击客户名字 -> 客户页 -> 左滑 / 返回：回到刚才那张订单。
- 客户页 -> 某订单 -> 左滑 / 返回：回到该客户页。
- 订单页 -> 左滑 / 返回：回到它实际进入前的页面。

## 实作

在「单张订单 -> 客户页」之前，先把当前 history entry 强制校正为该订单，
再 push 客户页 state。这样 iOS / Android 的浏览器边缘返回手势会落回精确订单，
不再落到客户页原本的上一层。
