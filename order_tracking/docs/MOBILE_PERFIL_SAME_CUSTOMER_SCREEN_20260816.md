# 手机单张订单 PERFIL 修正

本次只修改手机单张订单页，不修改桌面 Web，也不重做「按客户」页面。

修正后的逻辑：
- 首页「按客户」 -> 点 NELSON：进入现有 NELSON 客户页面。
- 首页「按订单」 -> 点 1008212-1 -> 单张订单页 -> 点顶部 PERFIL：进入完全相同的 NELSON 客户页面。
- 不存在第二套 PERFIL / 客户详情实现。
- PERFIL 放在单张订单页最上方，类似小红书作者/账号入口。
- 点击 PERFIL 后可以看该客户全部订单；再点任何订单进入该单页。
- 浏览器返回会从客户页回到刚才那张单。
- 返回箭头仍为悬浮式，不额外占一行。
