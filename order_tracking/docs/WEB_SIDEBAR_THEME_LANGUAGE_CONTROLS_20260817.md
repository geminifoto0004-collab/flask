# Web 侧边栏：主题 / 语言控制位置调整

本次只调整桌面 Web 的控制位置与图标风格，不改变主题、语言切换逻辑。

- 桌面侧边栏顶部移除原本的白色胶囊 `☾ / ☀` 与 `ES / 中文`。
- 主题与语言切换移到侧边栏底部，紧邻当前登录用户与登出按钮。
- 主题图标由字符改成与侧边栏一致的线性 SVG 月亮 / 太阳。
- 语言按钮增加线性 SVG 地球图标，并保留 `ES / 中文` 文字提示。
- 侧边栏折叠时，主题、语言、登出仍可用；语言只显示地球 SVG，以免 70px 宽度拥挤。
- 手机顶部仍保留原来的主题 / 语言入口；主题图标同步改成 SVG。
- 登录页主题图标也同步改成 SVG。
