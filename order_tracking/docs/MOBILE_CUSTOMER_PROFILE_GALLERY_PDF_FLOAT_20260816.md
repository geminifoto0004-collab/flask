# 手机：客户 PERFIL 图库 + 本单 PDF 悬浮动作

仅修改手机版，桌面 Web 不改。

## 单一订单页
- 客户信息区改成 PERFIL 入口。
- 点击客户名称 / 头像 / PERFIL，可直接进入该客户主页。
- 本单 PDF 不再放在页面最下面。
- 改成右下固定悬浮「本单 PDF」按钮，任何滚动位置都能点。
- 点击后仍使用既有 PDF 设置：语言、图片来源、数量、顺序，再进入后台队列。

## 客户 PERFIL
- 客户所有订单改成图片网格，更接近小红书 Profile。
- 每张订单显示一张封面图 + 订单号 + 状态。
- 封面优先取订单图片；没有订单图片才用流程 / 业务员图片。
- 没图时显示订单号占位。
- 点任一封面进入该订单；单一订单页仍可以左右看该订单全部图片。
- 封面采用最多 4 个并发请求加载，避免一次客户很多订单时同时发几十个图片请求。

## History
- 单页订单 -> PERFIL 会形成站内 history。
- 从 PERFIL 点订单 -> 返回时仍回 PERFIL，并保留刚刚订单的焦点。
