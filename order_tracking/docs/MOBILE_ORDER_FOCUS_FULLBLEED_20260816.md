# 手机订单模式：客户订单优先 + 小红书式满宽主图

本次只修改手机，不修改桌面 Web。

## 按订单模式
默认重点是客户订单：
- 一般订单号：全部显示，按订单号倒序。
- G / KC 开头但已经有客户：保留，但排在一般订单之后。
- G / KC 开头且没有客户：默认不占列表。
- 如果用户明确搜索某个 G / KC 号，仍可以搜出来。

按客户模式：
- G / KC 有客户的订单会正常归到该客户。
- 无客户的 G / KC 不再形成「未指定客户」噪音组。

## 单一订单详情
- 删除「返回订单列表」占用的独立行。
- 返回键改成悬浮圆形箭头，不占主图空间。
- 有图时覆盖在主图左上角。
- 无图时覆盖在订单 hero 左上角，并为内容留出空间。
- 主图改为 full-bleed，突破手机页面左右 10px padding。
- 不再强迫 4:3 / 4:5 比例。
- 图片以自身比例按 100% 横向宽度显示。
- 多张图片的圆点放在主图正下方，当前圆点使用品牌红。
- 文件来源 / 文件名放在圆点下面。
