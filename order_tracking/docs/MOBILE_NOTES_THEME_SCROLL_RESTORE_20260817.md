# 手機備註 / 深淺色模式 / 客戶圖庫返回定位修正

更新：2026-08-17

## 1. 單一訂單詳情顯示備註
- 本地手機版單一訂單頁新增「備註」區塊。
- 備註使用完整文字顯示，保留換行。
- 雲端 / Render 模式仍不顯示 notes，維持 TiDB 安全摘要原則。

## 2. 全站 Light / Dark Theme
- 新增 `static/js/theme.js`，在首屏 CSS 前套用主題，避免閃白。
- 新增 `static/css/theme.css`，並安排在各頁面 CSS 後載入，作為全站最後一層主題覆寫。
- 手機頂部列、桌面側欄標題、登入頁新增 ☾ / ☀ 切換按鈕。
- 偏好存入 `localStorage(orderTrackingThemeMode)`；第一次使用時跟隨系統主題。
- 主題只影響 UI，不改資料庫、API、權限或訂單資料。

## 3. 按客戶 -> 訂單 -> 左滑返回的位置修正
- 進入訂單前除了保存 `scrollTop`，也保存被點擊卡片在可視區中的相對 Y 位置。
- 左滑 / Back 回客戶圖庫時，先還原 scrollTop，再以原訂單卡片作為 anchor 做二次校正。
- 移除回到客戶圖庫時的 `scrollIntoView()`，避免瀑布流重新排版後把頁面拉到錯誤位置。
- 目標：回來後原本點擊的訂單仍停在幾乎相同的螢幕位置，不必重新往下找。
